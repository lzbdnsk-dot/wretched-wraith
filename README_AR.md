# مشواري 1.1 — تسجيل الدخول برقم الهاتف

## ما تمت إضافته
- Firebase Core وFirebase Authentication.
- شاشة تسجيل دخول برقم عراقي بصيغة +964.
- إرسال رمز OTP عبر SMS.
- التحقق من الرمز وتسجيل الدخول.
- التحقق التلقائي على بعض أجهزة Android.
- استعادة الجلسة عند إعادة فتح التطبيق.
- تسجيل الخروج.
- واجهة الراكب والكابتن بعد تسجيل الدخول.

## إعداد Firebase (ضروري قبل التشغيل)
1. أنشئ مشروعاً في https://console.firebase.google.com/
2. أضف تطبيق Android وتطبيق iOS إلى مشروع Firebase.
3. فعّل Authentication ثم Sign-in method ثم Phone.
4. أضف ملفات إعداد Firebase:
   - Android: ضع `google-services.json` داخل `android/app/`.
   - iOS: أضف `GoogleService-Info.plist` إلى مشروع Runner في Xcode.
5. شغّل:
```bash
flutter pub get
flutter run
```
6. على Android تأكد من إعداد SHA-1 وSHA-256 في إعدادات تطبيق Firebase. قد تحتاج إعدادات Play Integrity أو reCAPTCHA حسب الجهاز.
7. على iOS أكمل إعداد APNs ورفع مفتاح APNs إلى Firebase، كما يلزم إعداد URL scheme عند الحاجة وفق دليل Firebase.

## ملاحظات مهمة
- لا يمكن إرسال SMS حقيقي قبل إعداد مشروع Firebase ووسيلة التحقق.
- لا تستخدم رقمك الحقيقي للاختبار المتكرر؛ يمكنك إضافة أرقام اختبار ورموز ثابتة من Firebase Authentication في بيئة التطوير.
- صيغة الرقم في الواجهة: 10 أرقام تبدأ بـ 7، ويضيف التطبيق +964 تلقائياً. عدّل التحقق إذا أردت دعم صيغ شركات/أرقام أخرى.
- هذه النسخة تثبت رقم الهاتف فقط. اختيار دور راكب/كابتن وحالة اعتماد السائق يجب حفظهما في قاعدة بيانات خادمية لاحقاً؛ لا تمنح صلاحيات الكابتن اعتماداً على اختيار محلي داخل التطبيق.
- لا تضع مفاتيح سرية أو صلاحيات الإدارة في تطبيق الهاتف.
